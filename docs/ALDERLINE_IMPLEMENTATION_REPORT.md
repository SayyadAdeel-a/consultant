### AI Artifact Remediation
- **The Issue:** Source assets `IMG-001` (Dark Logo) and `IMG-002` (Light Logo) were generated by an image diffusion model that baked a 100% opaque checkerboard transparency grid directly into the pixels of the JPG. When placed against `#f6f2eb`, this produced visual ugliness.
- **The Resolution:** Handcrafted companion vector SVG logos (`logo-dark.svg` and `logo-light.svg`) with an organic leaf emblem and tracking-adjusted serif/sans typography were placed in `public/assets/alderline/brand/` and wired into `Navbar.tsx` and `Footer.tsx`. The original JPG assets were retained in the repository manifest for reference.
- **Icon Blending:** For white-ground icon JPGs (`IMG-008`–`IMG-011`, `IMG-019`–`IMG-021`), CSS `mix-blend-mode: multiply` was applied so their backgrounds melt seamlessly into the warm sand cards.

## 5. Animation & Motion Integrity

All GSAP and CSS animations were preserved and verified:
1. **Title Stagger Animations (`title-anim`):** Uses SplitType to split words/characters and animate them smoothly upwards on scroll.
2. **Fade Animations (`fade-anim`):** Staggered opacity and translateY transitions triggered by ScrollTrigger.
3. **Image Parallax Animations (`image-anim`):** Soft scale-in and vertical parallax scrub on photographic containers.
4. **Interactive Text Rolls (`text-roll`):** Dual-layer CSS transforms creating fluid vertical rolling typography on button and link hover.
5. **Pin & Accordion Sequences:** Smooth height transitions on FAQ drawers and mega-menu dropdowns.
